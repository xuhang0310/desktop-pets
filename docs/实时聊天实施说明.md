# 实时聊天首版实施说明

本次依据 Claude 的《实时聊天方案》实施第一阶段，并准备第二阶段的调用接口与训练素材工具。原方案保留在同目录，作为分阶段目标。

## 使用

重新启动桌面伙伴，点击人物右侧最上面的聊天气泡按钮，打开蓝色聊天面板。点击面板右上角齿轮，填写模型服务地址、模型名和 API Key，保存后返回聊天。

支持千问、DeepSeek 及其他 OpenAI 兼容的 Chat Completions 接口。服务地址填基础地址，例如 `https://服务域名/v1`；也可填写以 `/chat/completions` 结尾的完整地址。千问预设使用仍受支持的北京旧域名，可按控制台显示的地域和业务空间地址修改。密钥必须和服务地址对应。

按 Enter 发送，Shift+Enter 换行。发送后逐字显示回复，语音按句合成和播放。停止按钮、点击人物、切换形象、开始麦克风互动、拖动或收起窗口都会取消当前聊天。鲸鲸与小小分别保存记忆；设置中的“清空当前伙伴的记忆”只清空当前人物。

## 声音选择

- **在线自然女声**：使用现有 Python 的 `edge-tts`。已用短句实测生成并解码。回复文字会发送到在线语音服务；这是女声朗读，音色与鲸鲸 A 版不同。
- **鲸鲸复刻 · 本地 GPT-SoVITS**：先准备并启动本地 `api_v2.py` 服务，再填写本机地址、参考 WAV 完整路径及参考原文。小小继续使用自己的在线自然女声。
- **只显示文字**：不请求实时语音。

鲸鲸的点击互动继续播放 `assets/voice-dafeiyu-indextts2-a/` 的 19 段样本，小小继续使用原有 18 段样本。实时回复不会改写这些文件。

参考 A 音频：`voice-lab/dafeiyu-indextts2/calibration/reference-voice-only.wav`，视频区间 1.74–4.98 秒。参考原文请核对该 WAV 的实际内容后填写；服务需要与参考和目标音色匹配的权重。

本地复刻服务失效时，默认保持文字回复；勾选“本地服务离线时，改用在线女声”后才会使用在线回退。故障提示每条回复最多一次。

## 训练素材工具

```powershell
# 仅导出已有的 19 段 A 版母音频，不加载显卡模型
& 'D:\workspace\index-tts2\.venv\Scripts\python.exe' scripts/generate-sovits-dataset.py

# 检查显卡没有其他生成任务后，制作 100 句教师语料；可再次执行续做
& 'D:\workspace\index-tts2\.venv\Scripts\python.exe' scripts/generate-sovits-dataset.py --generate

# 只制作选定的一句
& 'D:\workspace\index-tts2\.venv\Scripts\python.exe' scripts/generate-sovits-dataset.py --generate --line train-001
```

输出在 `voice-lab/dafeiyu-sovits-dataset/`：32kHz 单声道 WAV、`dataset.list`（`路径|jingjing|zh|文本`）、语料及校验报告。脚本复用已确认的 A 版参考和教师设置；逐条写入报告，校验文本、参数和音频哈希后跳过已完成片段，始终不修改生产语音包。导出后的素材仍需在 GPT-SoVITS WebUI 中训练和试听，才能验收实时复刻效果。

## 配置和数据

配置保存为 `userData/chat-config.json`。API Key 用 Windows 上的 Electron `safeStorage` 加密；配置读取只返回是否已有密钥，不返回原文。系统加密不可用时拒绝保存密钥。改变模型服务地址时移除旧密钥，防止误发给另一个服务；请重新输入对应密钥。加密文件换到另一台电脑或另一个 Windows 账户时通常需要重新输入密钥。

记忆保存为 `chat-memory-jingjing.json` 和 `chat-memory-xiaoxiao.json`。最近 20 轮进入模型上下文；超过 20 轮后后台生成最多 1600 字摘要，保留最近 16 轮。摘要失败时继续保留最多 24 轮原文，不影响聊天。关闭记忆后不向模型发送历史或新增记忆；本机仍可查看原有历史，需要移除旧数据时使用清空按钮。

模型请求最多等待 90 秒，单句 TTS 最多等待 30 秒。模型输出最长 1800 字，最多合成 16 段；句子过长时在边界拆分。隐藏的思考字段和跨片段 `<think>` 内容不显示、不朗读、不写入对话记忆。

功能标签是白名单，不能运行代码、访问任意文件或调用其他应用。待办、计时操作还检查用户当前消息是否明确要求相应功能。界面用 `textContent` 显示模型输出，密钥不进入日志或语音请求。

后端测试使用本机 HTTP 模拟接口，检查碎片化 UTF-8/SSE、思考分流、切句、首句提前合成、角色隔离、停止、错误、记忆摘要、密钥与 IPC 校验，以及 GPT-SoVITS 请求和 WAV 格式。界面测试使用真实 Electron preload/IPC、加密存储、MP3 解码和按句播放，不打开麦克风、不调用付费模型。它们不能代替真实云端服务或复刻权重的音色与延迟验收。
